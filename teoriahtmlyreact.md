1. HTML
HTML: lenguaje utilizado para crear y estructurar páginas web.
Estructura: <html>, <head>, <title>, <body>, <header>, <nav>, <main>, <section>, <footer>.
Video: se utiliza la etiqueta <video>.
5 etiquetas de texto:
<h1> → título
<h2> → subtítulo
<p> → párrafo
<strong> → texto importante
<em> → texto enfatizado
2. JavaScript
Variables: almacenan datos. Se pueden declarar con let, const y var.
Tipos de datos: String, Number, Boolean, Undefined, Null, Object y Array.
Constantes: se declaran con const y no se pueden reasignar.
Estructuras de flujo: if, else, switch, for, while y do...while.
3. CSS
Selectores: permiten seleccionar elementos HTML para aplicarles estilos.
Principales: etiqueta, clase (.clase), ID (#id) y universal (*).
Ejemplo:
p {
  color: blue;
}

4. React
React: biblioteca de JavaScript para crear interfaces de usuario mediante componentes.
Componentes: partes reutilizables de una aplicación.
Props: permiten pasar información a los componentes.
useState: permite guardar y modificar datos que cambian dentro de un componente.
const [contador, setContador] = useState(0);

contador es el valor y setContador permite cambiarlo.
